The Mark
One symbol.
Three tiers.
Total clarity.
ADMIN — GOLD — ROW 0
TEACHER — CYAN — ROW 1
STUDENT — PEARL — ROW 2
The 3×3 mark is Stratosyn's canonical visual language. Every square encodes a role, a state, and a tier — simultaneously. Perimeter wraps clockwise: 0→1→2→5→8→7→6→3. It is not decorative. It is the system.

Truth Layer
Calibration
intelligence
Pipeline A — Externalizing
  • Observable / behavioral signals
  • Thresholds: T1 <6 · T2 6–12 · T3 12–18 · T4 18+
  • Sensitivity: 83.9% · Specificity: 80%
Pipeline B — Internalizing
  • Context / invisible / masking signals
  • Thresholds: T1 <8 · T2 8–14 · T3 14–24 · T4 24+
  • IC sensitivity: 62.5% · HP@T3+ soft-spot: 42.9%
Overall Tier = max(TierA, TierB)
  • T1 — Normative
  • T2 — Watch
  • T3 — Intervene
  • T4 — Escalate immediately
